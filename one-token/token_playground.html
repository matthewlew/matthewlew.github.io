7 Object Colors
System Architecture
Components only consume the 7 object colors. All visual variation comes from composing four class dimensions on their container.
1
Primitive Tokens
Raw hex values, never used in components. 11 steps per color family.
starbucks-500grey-200violet-800
2
Hue · color family
Resolves color-500 to the active hue's 500 step. Set on any container — a child banner can override the page hue.
StarbucksTealViolet+ custom
3
Mode · light or dark
Flips backgrounds and foregrounds. Applied globally here — click any component to see that a child could override this too.
LightDark
4
Emphasis · contrast level
How much the surface stands out. Click a component to set a different emphasis than the page — that's the core of the class inheritance model.
PlainSoftStrongStark
5
7 Object Colors · what components use
background · text · text-accent · text-subdued · icon · border · border-subdued. Every component only ever references these. The class combination above resolves their values.
AA
Accessibility enforcement
Text tokens require ≥ 4.5:1 against background. Blocked in the editor — you cannot produce a failing combination. Border tokens have no minimum.
